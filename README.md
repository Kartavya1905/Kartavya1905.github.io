# Kartavya Mandora · Portfolio

My AI/ML and software engineering portfolio, live at **https://kartavya1905.github.io**.

Built with Next.js (App Router), React and Tailwind CSS, exported as a static site and deployed to GitHub Pages.

## Editing content

All text, projects, skills and timeline entries live in `lib/data.ts`. The photo and resume are in `public/`.

## Running locally

```bash
npm install
npm run dev
```

## Deploying

Every push to `main` builds the site and publishes it through `.github/workflows/deploy.yml`.
